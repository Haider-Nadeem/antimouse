# antimouse

Spotlight-style search bar for the current web page. Press **Cmd+K** / **Ctrl+K** to toggle.

## Load it

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this folder

## Develop

Edit `content.js` — that's the only file with logic. Reload the page (or hit the
reload icon on the extension card) to see changes.
